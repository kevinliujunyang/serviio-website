常见问题

哪个 POS 可以自行连接？

Serviio 账户支持连接 Square、选择门店、检查 API 权限并加载菜单。其他 POS 的可用性需要按餐厅和服务商另行确认。

成功读取菜单是否代表厨房已经能收到订单？

不是。菜单读取只验证目录访问，不代表订单创建、支付、POS 显示或厨房打印已经正常。这些步骤都需要按门店分别测试。

口味和加料应该测试哪些内容？

使用真实菜单的必选项、尺寸、默认选项、加料、替换和数量规则进行测试。核对菜品与选项、计算出的价格，以及员工最终收到的订单内容。

连接 Square 会请求哪些权限？

账户页面会说明对商户资料与门店、菜品与价格、订单和支付的访问。权限允许创建订单和支付。顾客在 Square 托管结账页输入支付信息。连接本身不会下单或扣款。

使用其他 POS，或者还没有 POS 怎么办？

请提供现有系统以及订单如何进入厨房，以便检查兼容性。如果还没有 POS，请先说明当前流程并咨询设置建议，不应直接假定已有可用对接。
