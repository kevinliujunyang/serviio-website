Square 账户连接与电话接单设置

为 Square 餐厅准备 AI 电话接单

先连接您的 Square 门店，查看菜单，再与 Serviio 一起准备中英文电话接单的菜单、电话和订单交接流程。

创建账户并连接 Square需要设置帮助？

连接 Square 本身不会下单、扣款或开通电话接单。语音接单和厨房流程需要另外配置并测试。

开始前请准备

  • 可接收登录邮件的邮箱
  • 餐厅名称、联系人及电话
  • 有权批准应用访问的 Square 账户
  • 要连接的门店及其菜单目录

从注册到账户连接

  1. 1. 用邮箱创建账户

    输入邮箱，打开收到的登录链接并确认登录。首次验证登录会创建账户。

  2. 2. 保存餐厅资料

    填写餐厅名称、联系人和电话，然后保存。

  3. 3. 在 Square 授权

    点击“连接 Square”，在 Square 登录并查看、批准所需权限。

  4. 4. 选择门店并查看菜单

    保存要连接的门店，检查 API 权限并加载菜单。与我们确认菜单选项、电话和厨房交接流程后，再安排测试与开通。

Square 连接常见问题

连接 Square 后会自动开始接单吗？

连接 Square 本身不会下单、扣款或开通电话接单。语音接单和厨房流程需要另外配置并测试。

Serviio 需要哪些 Square 权限？

授权涉及商户资料与门店、菜单与价格、订单和支付。权限允许创建订单及支付，顾客在 Square 托管结账页输入支付信息。您可在 Serviio 账户中断开连接。

在哪里查看菜单？

登录后保存餐厅资料、连接 Square 并选择门店，然后点击“加载菜单”。菜单结果取决于该门店的目录；请检查菜品、价格和选项。读取菜单不会创建订单或支付。
